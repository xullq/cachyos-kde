# CachyOS KDE Plasma Setup (Dual Monitor Minimal)

Minimalistinen, nopea ja suorituskykyinen KDE Plasma -asennus CachyOS:lle (erityisesti kahdelle näytölle).

## Tavoite
- Karsittu Plasma-ydin ilman ylimääräistä KDE-ohjelmistospagettia (ei Akonadia, Baloo-indeksointia tai turhia taustaprosesseja).
- Valitut, tarkoituksenmukaiset sovellukset omiin tarpeisiin.
- Saumaton Wayland-moninäyttökokemus (eri virkistystaajuudet, omat ikkunasäännöt).

## Rakenne
- `packages/` - Ohjelmistolistaukset kategorioittain
- `scripts/` - Optimointi- ja konfiguraatioskriptit
- `.config/` - Työpöydän ja sovellusten asetukset
- `install.sh` - Asennusskripti
